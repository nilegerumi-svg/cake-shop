# 第二批移植（增量包，非最终包）

## 这批做了什么
把第一批留下的「人物志共 0 人」接通：4 个数据桥 + 51 位镇民的 v53 增量档案。
带真实存档进主界面验证：人物志渲染 58 行，「最爱」显示中文名，隐藏关系按好感门槛显隐。

## 关键判断
比对发现 v53 的镇民档案比仓库**更全**（隐藏关系、送礼台词、关系网），
所以不是「写个桥投仓库旧数据」，而是先把增量字段补进 js/data，再投影成桥。
数据仍只有一份，bundle 分片一个没动。

## 怎么应用
upload/ 按相对路径覆盖到仓库根目录。两处是「改一行」，若已有别的改动，
用 patch/接线片段.txt 手工追加，不要整体覆盖。

## 已知限制
熟客簿能显示，但「登记熟客」写入不回写（v53 拿的是 React 活 state，仓库没有）。
详见 upload/docs/第二批移植清单.md。tools/ 内为可复现的比对与验证脚本。
