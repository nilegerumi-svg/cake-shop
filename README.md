## 这是什么

一款纯前端、移动端优先的蛋糕店模拟经营游戏。从上手第一天起，你要经营「街角甜品屋」：进货、烘焙、上架、开店卖货、和镇上的邻居打交道，在四季与节气里把小店做大。

> 当前线上版本为 **灵光闪（React）版**，界面与交互为该版本的现成实现。

---

## 核心玩法

- **🏠 小楼（经营中枢）**
  - 1F：店面 · 厨房 · 家具工坊
  - 2F：卧室 · 阳台
  - 3F：书房 · 收藏
  - B1：地下室
  - 天台：观星 / 天气
  - 可「开店营业 / 收摊」、查看货架（6 格）、待上架、店内家具、店铺魅力 Lv、交涉技能、外卖热线、员工招聘、出门去小镇。
- **📦 订购**：食材按分类（五谷 / 蛋奶 / 水果 / 糖巧 / 肉禽 / 蔬果 / 水产 / 调味 / 其他）下单，次日一早送达；`+1` / `+5` 批量订购。
- **📱 通讯**：镇上的 NPC 伙伴，聊天与好感。
- **🗂️ 档案**：个人状况、熟练图鉴、人际关系、认识伙伴、健康档案、声望、技能总览。
- **🏆 成就**：成就殿堂（116 项）+ 荣誉墙 + 里程碑奖励 + 存档管理（含重新启动游戏）。

### 状态与压力

角色有 **钱 / 精力 / 心情 / 健康 / 饱食 / 店铺卫生 / 声望 / 等级** 等状态。饿着肚子营业会掉饱食 → 精力、心情、健康一起掉；不睡觉会疲劳。想赚钱就要在「进货花钱」和「卖货回本」之间平衡。

### 季节 / 天气 / 节气

每季 30 天，顶栏实时显示：天气、星期、季节、节气、第 N 天、日期。

## 界面与适配

- **PC 宽屏**：768px 起容器 **720px**；1200px 起 **820px**，字号随之上调（16.5 / 17.5px），两侧留暗色背景。
- **平板 / 小屏 / 横屏 / 刘海屏**：见 `css/adapt.css`（安全区、小屏收紧、横屏压缩顶栏）。
- **滑动**：左右滑动切换底部标签；键盘 `Alt + ←/→` 也可切换（`js/host/swipe.js`）。
- **盲人模式**：开始页可「立即开启」，进入游戏后有语音播报；弹窗正文自动放大。
- **夜间模式**：顶栏可切换，弹窗同步深色。
- **统一弹窗**：除手机界面（`.modal-sheet-phone`）外，所有弹窗统一卡片外观与文字排版（`css/modal.css`）。

## 技术说明

- **纯静态托管**：无需服务器，GitHub Pages 直接部署。
- **外壳 + iframe 面板**：主页面负责顶栏、标签、状态与弹窗；内容面板通过 iframe 挂载，切换时不整页刷新。
- **宿主增强脚本**：在不改动打包产物的前提下，通过 `css/adapt.css`、`css/modal.css`、`js/host/swipe.js` 增加适配、滑动与弹窗统一。
- **无障碍**：内置盲人模式与语音播报；键盘可操作；焦点环统一。
