## 二、衰减逻辑（每小时）

### 1. 饱食/精力/心情/健康衰减 `Fe(state, hours)`

```
dA = 2   // 饱食每小时衰减
uA = 3   // 精力每小时衰减
mA = 2   // 心情每小时衰减
fA = 1   // 健康每小时衰减

satiety = max(0, satiety - hours * dA)
if satiety <= 0:
    energy = max(0, energy - hours * uA)
    mood   = max(0, mood   - hours * mA)
    health = max(0, health - hours * fA)
```

> 关键点：**只有饱食归零后，精力/心情/健康才会开始掉**。也就是说「饥饿」是心理与健康损耗的开关。

### 2. 心情随机衰减 `tn(state, hours)`

```
cA(n) = max(1, round(n/6 + random() * (n*7/9 - n/6)))
mood  = max(0, mood - cA(hours))
```

> 心情衰减带随机浮动（6 分之一到 9 分之七之间），不可预测，模拟情绪波动。

### 3. 食物/事件对三项状态的影响（示例）

- 吃好饭：`satiety +40`、`energy +10`、`mood +4`
- 吃难吃的东西：`satiety +12`、`health -6`、`mood -3`
- 节日活动：`mood +6 ~ +10`、`energy -4 ~ -8`、`health 0`
- 受伤：`health -= 受伤值`、`stats.injuries += 1`

## 四、诊断规则 `SI(state)`（按顺序匹配，命中即返回）

| 优先级 | 条件 | 诊断 | 治疗 |
|---|---|---|---|
| 1 | 天气 `rain / storm / snow` | 淋雨受凉（天气湿冷，户外着了凉） | 输液驱寒 + 开感冒药，注意保暖 |
| 2 | 高温晴天（`sunny/cloudy` 且当日高温） | 中暑（高温天体力透支，身体过热） | 输液降温 + 静养建议，多喝水 |
| 3 | `satiety <= 0` | 肠胃不适（饮食不规律，饿过头伤了胃） | 开胃药调理 + 清淡饮食建议 |
| 4 | 今日未睡（`sleptToday <= 0`） | 疲劳过度（长时间熬夜未休息） | 输液补充 + 静养建议，保证睡眠 |
| 5 | `stats.injuries > 0` | 外伤（劳作或意外磕碰导致） | 清创包扎 + 消炎药，注意伤口卫生 |
| 6 | 其他 | 疲劳过度（身体状态欠佳，过度劳累） | 静养建议 + 开维生素补充 |

> 「疾病与心理」= **天气致病 + 饥饿伤身 + 熬夜伤神 + 外伤 + 心情衰减** 的组合，全部由上面这套状态与规则驱动，没有独立的「疾病表」。

## 五、当前旧版代码的引用完整性（结论）

**不完整 —— 旧版基本没有引用这套系统。**

旧版 `js/core/schema.js` 的 `createEmptyState()` 只定义了：

```
money / energy / maxEnergy / currentLocation / time / shop / skills /
recipeProf / tools / inventory / orders / foods / characters / unlockedRecipes
```

对照结论：

| 新版字段/能力 | 旧版是否有 | 说明 |
|---|---|---|
| `energy` 精力 | ✅ 有 | 旧版有，且是核心资源 |
| `mood` 心情 | ❌ **无** | 旧版存档里根本没有该字段 |
| `health` 健康 | ❌ **无** | 同上 |
| `satiety` 饱食度 | ❌ **无** | 旧版没有饥饿机制 |
| `stats.injuries` 外伤 | ❌ 无 | 旧版没有受伤计数 |
| `healthRecords` 健康档案 | ❌ 无 | 旧版没有就诊记录 |
| 天气致病（感冒/中暑） | ❌ 无 | 旧版无天气系统联动 |
| 医院/看病 | ❌ 无 | 旧版没有医院地点逻辑 |
| 心情随机衰减 | ❌ 无 | 旧版无心情 |

**因此：** 旧版对「疾病与心理」的引用是**缺失的**，只有 `energy` 这一项被用到。要让这块真正可用，需要在旧版状态里补 `mood / health / satiety / stats.injuries / healthRecords` 五个字段，并接入上面的衰减、诊断、看病逻辑。

> 数据结构已导出到 `js/data/health.js`（`Cake.HEALTH_SYSTEM`），逻辑全文即本文档。
