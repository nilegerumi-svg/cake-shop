# 第一批移植清单（v53 → 仓库层级）

> 依据：仓库既有文件夹层级（`css/` 放样式、`js/host/` 放原生 DOM 手写块、
> `index.html` 接线、`docs/` 放接线文档）。本批不新造目录、不改命名规则。
> 来源：`甜蜜物语-离线版-v53.html` 的「手写可读区」（`tm-*` 块）。
> 性质：**增量批次**，不是最终包。后续批次继续在同一克隆目录累积。

## 一、本批搬了什么

只搬「v53 新增、仓库缺独立文件」的 7 个只读手写块，正文逐字取自 v53，不改写、不重排。

| `tm-people-style` | `css/people.css` | 3720 | 人物志样式（含夜间主题） |
| `tm-people-script` | `js/host/people.js` | 17775 | 人物志 + 熟客簿两个悬浮面板 |

## 四、已知遗留（后续批次候选，本批不处理）

1. **3 个数据桥缺失**：仓库 bundle 中 `__TM_NPC__` / `__TM_ITEM_MAP__` /
   `__TM_AFF_GET__` 均为 0 处（v53 分别 14 / 9 / 7 处）。后果：人物志能开，
   但显示「数据接自游戏档案库，共 0 人」。`__TM_LONG_PROFILES__` 与
   `__TM_WALL_SCROLL__` 由本批自带，文案墙、熟客簿数据自足可用。
2. 仓库 bundle **已含** `__tmPsych`（8 处）、`nightMarketPermit`（20 处），
   心理系统与夜市逻辑无需从 v53 重搬。
3. v53 主程序包**内部**散落的手写注入（熟客簿钩子、雨天动向、隐藏关系、
   天气客流、双重节日备忘等，多带 2026-11-13/14 拍板日期）不在「手写可读区」，
   属 bundle 层，需单独定位，留待后续批次。
4. `docs/内容接线清单.md` 记录的 397 个「仅存在于 bundle、尚未下沉到
   `js/data/`」的静态数据对象，是数据层后续接线的既定范围，本批未触碰。
