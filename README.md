## 这是什么

一款纯前端、移动端优先的蛋糕店模拟经营游戏。从上手第一天起，你要经营「街角甜品屋」：进货、烘焙、上架、开店卖货、和镇上的邻居打交道，在四季与节气里把小店做大。

> 当前线上版本为 **灵光闪（React）版**，界面与交互为该版本的现成实现。

## 核心玩法

- **🏠 小楼（经营中枢）**
  - 1F：店面 · 厨房 · 家具工坊
  - 2F：卧室 · 阳台（**小睡 +45 精力** / **一觉睡到明早**，直接进入第二天）
  - 3F：书房 · 收藏
  - B1：地下室
  - 天台：观星 / 天气
  - 可「开店营业 / 收摊」、查看货架（6 格）、待上架、店内家具、店铺魅力 Lv、交涉技能、外卖热线、员工招聘、出门去小镇。
- **📦 订购**：食材按分类（五谷 / 蛋奶 / 水果 / 糖巧 / 肉禽 / 蔬果 / 水产 / 调味 / 其他）下单，次日一早送达；`+1` / `+5` 批量订购。
- **📱 通讯**：镇上的 NPC 伙伴，聊天与好感。
- **🗂️ 档案**：个人状况、熟练图鉴、人际关系、认识伙伴、健康档案、声望、技能总览。
- **🏆 成就**：成就殿堂（116 项）+ 荣誉墙 + 里程碑奖励 + 存档管理（含重新启动游戏）。

### 状态与压力

角色有 **钱 / 精力 / 心情 / 健康 / 饱食 / 店铺卫生 / 声望 / 等级** 等状态。饿着肚子营业会掉饱食 → 精力、心情、健康一起掉；不睡觉会疲劳（熬夜过夜健康 -12）。想赚钱就要在「进货花钱」和「卖货回本」之间平衡。

### 季节 / 天气 / 节气

每季 30 天，顶栏实时显示：天气、星期、季节、节气、第 N 天、日期。

## 界面与适配

- **五档布局，父页唯一决策**：由 [js/host/layout-sync.js](js/host/layout-sync.js) 统一判定并给父文档与每个面板 iframe 挂同名属性，iframe **不按自身宽度判断**（帧宽度比父容器窄 32~68px，会导致上下层缩放不一致）。暴露 `window.__cakeLayoutMode`（`compact`/`wide`/`fold`/`slim`/`phone`）与 `__cakeLayoutCompact` / `__cakeLayoutSlim` 等标志。档位互斥，优先级 `compact > wide > fold > slim > phone`。
  - `wide` **桌面鼠标放大档**（非粗指针 + 宽 ≥768 + 高 ≥560）：内容列 **1080px 居中**（手机版 600px × 1.8 倍），根字号 **32px**（`--player-font-scale:2` / `--fs` 驱动），两侧深色背景；顶栏、标签栏、弹窗、语音钮对齐到 1080 列。规则见 [css/pc-layout.css](css/pc-layout.css)、[css/adapt.css](css/adapt.css)、`index.html#pc-inline` 与 [css/frame-wide.css](css/frame-wide.css)，全部以 `html[data-tm-wide]` 属性驱动。
  - `fold` **宽屏触屏 / 书本式折叠展开档**（粗指针 + 宽 ≥641 + 高 ≥560）：**保持 16px 基准字号不放大**，放开 `@media(min-width:641px)` 写死的 560px 内容列，让大屏铺满（[css/fold.css](css/fold.css)）。设置中心的字体倍率在本档仍然生效。
  - `compact` **翻盖外屏 / 超矮触屏档**（粗指针 + 高 ≤440，对应 moto razr 合盖 352×355 ~ 424×360）：顶栏强制收起并压到 ~82px、页签收紧到 ~62px、弹窗 `max-height` 提到 `calc(100dvh - 12px)` 占满屏幕；收起后工具行消失，由 [js/host/compact-entry.js](js/host/compact-entry.js) 注入常驻 ☰ 浮动菜单访问手册 / 设置 / 引导 / 库存（[css/razr.css](css/razr.css)）。
  - `slim` **细长竖屏档**（粗指针 + 高 ≥700 + 高宽比 ≥2.05，对应 razr 22:9 内屏 360×780 ~ 412×915 及普通细长手机）：只压缩顶栏内部留白与徽章字号，**不收起任何组、不隐藏任何按钮**，顶栏 495→192px、内容区翻倍，手册 / 设置入口常驻。
  - `phone` **手机档**（其余）：中等宽度竖屏、桌面窄窗口等，沿用原生版式。
- **翻盖式竖折（moto razr）**：展开内屏宽只有 360~412px，**不会触发 `fold`**；物理开合是 `compact ↔ slim` 的连续切换且不重载页面。[js/host/auto-collapse.js](js/host/auto-collapse.js) 在 compact 档强制收起顶栏并忽略手动折叠标记，避免「外屏手动展开 → 再合盖顶栏 540px 超过视口、内容区 8px」的不可逆死锁；离开外屏时清理该标记让布局自动恢复。顶栏收起态（含 360 宽内屏、344 宽外屏、手机横屏）统一由 ☰ 浮动入口兜底；v26 起该菜单扩到 8 项，并把合盖外屏的四个常驻浮层收进来（人物志／熟客簿／文案墙／语音指令），避免压住仅约 203px 的内容区。详见第十、十一章。
- **平板 / 折叠屏 / 小屏 / 横屏 / 刘海屏**：见 [css/adapt.css](css/adapt.css)。安全区由 `env(safe-area-inset-*)` 适配；≤360px 字号收紧到 14px；横屏矮屏（高 ≤560px）压缩顶栏把空间让给内容。**手机横屏（如 844×390）与折叠屏展开横屏都不再被误判成 PC 放大档**。iframe 内输入框聚焦时用 `visualViewport.height` 判断可见底边，避免 iOS 软键盘挡字。设备矩阵体检见第八章、书本式折叠屏专项见第九章、翻盖式竖折（razr）专项见 [docs/已知问题与修复.md](docs/已知问题与修复.md) 第十章。
- **触摸手势**：左右滑动切换底部标签，在 iframe 内容区与外壳区域同样生效；键盘 `Alt + ←/→` 等效（[js/host/swipe.js](js/host/swipe.js)）。手势层自动挂到每个面板 iframe 的文档，跳过以弹窗形式打开的「手机」入口并循环切页；采用「滑动优先、点击兜底」，从按钮上起手也能滑，切页后吞掉浏览器补发的 click 避免误触按钮。纵向滚动仍由 [js/host/panel-autofit.js](js/host/panel-autofit.js) 的软件惯性管线负责：明显横向手势整体让位给切页，编辑控件（输入框等）恢复选字与长按菜单，PC 鼠标桥的合成事件不会被误判为切页。小镇视图底部栏是 4 个动作按钮，不参与滑动切页。完整缺陷清单与分工见 [docs/已知问题与修复.md](docs/已知问题与修复.md) 第七章。
- **盲人模式**：开始页可「立即开启」，进入游戏后有语音播报；弹窗正文自动放大；点不到内容时会语音提示。
- **夜间模式**：顶栏可切换，弹窗同步深色。
- **统一弹窗**：除手机界面（`.modal-sheet-phone`）外，所有弹窗统一卡片外观与文字排版（[css/modal.css](css/modal.css)）。
- **减少动态效果**：尊重系统 `prefers-reduced-motion`，自动关闭动画与平滑滚动。
- **键盘可达**：统一可见焦点环；`Esc` 关闭弹窗；图标按钮自动补中文 `aria-label`。
- **UI 体检 v26**：右下人物志／熟客簿／文案墙改为 `104/148/192px` 三级阶梯，盲模式语音指令钮移到左下，四者零重叠；主底栏第三格由「通讯」正名为「手机」；手册与新手引导不再向玩家暴露内部「主线／系统」术语（主线仍只在系统内部推进）；文案墙按店主意思保留，并明确「日志」栏为**开发日志**，逐轮记录体检与修复。详见 [docs/已知问题与修复.md](docs/已知问题与修复.md) 第十一章。

## 技术说明

- **纯静态托管**：无需服务器，GitHub Pages 直接部署。
- **外壳 + iframe 面板**：主页面负责顶栏、标签、状态与弹窗；6 个内容面板通过 iframe 挂载，切换时不整页刷新。面板高度由 [js/host/panel-autofit.js](js/host/panel-autofit.js) 随内容自适应，因此页面表现为**一条纵向长页整体滚动**，面板内部不再有各自的滚动条。
- **跨文档只用 postMessage**：外壳与面板之间通过 `frame:theme`（主题 / 字号 / 盲人模式）、`frame:ready`、`frame:save-focus` / `frame:restore-focus`（切换标签时保留焦点）、`frame:pointerdown`、`flash-app-error`（面板异常上报）等消息通信，不跨文档读写 DOM，避免被浏览器安全策略拦截。
- **手写区与打包区分明**：原 `app.bundle.js` 是打包压缩产物；现已被逆向为可读源码并拆到 `js/src/`（按功能域 56 个模块，单文件均 ≤100KB，`app.bundle.js` 仅作「按序拼接执行」的加载器，不承载逻辑）。所有增强仍以 `tm-` 前缀的手写 CSS / JS 叠加实现，可读可维护；逆向源码的标识符已完成一轮系统性语义还原（`Eo`→`GLOBAL_OBJECT`、`Zc`→`playActiveTrack` 这类，约 98.5% 的全局符号），可直接按名检索阅读；改业务逻辑请优先在 `tm-` 手写区或对应 `js/src/<域>/` 模块进行。详见 `docs/逆向源码说明.md`。
- **无障碍**：内置盲人模式与语音播报；键盘可操作；焦点环统一；`aria-label` 自动补齐。

## 内容回归校验

每次把数据从 bundle 下沉到 `js/data/`（见 [docs/内容接线清单.md](docs/内容接线清单.md)）后，用字段级校验器确认内容没有被搬坏：

```bash
# 以离线包 / 概念版为基线，逐字段验证项目 js/ 中同名同值（引号、空白、键序、!0/!1 均不敏感）
node tools/verify-content.js "甜蜜物语蛋糕店-离线版 (4).html"
# 末行输出命中率，退出码 0 = 零差异
```
